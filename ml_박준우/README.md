# ml_박준우 — 17개 시도 6개월 누적 월세 변화율 예측

전처리본(`데이터취합_전처리_20261004.xlsx`, `17시도_2차_공표시점반영(ML용)` 시트)에서 다시 시작한 분석이다.
기존 `ml/` 폴더의 코드·결과는 쓰지 않는다.

## 실행

```bash
python step1_check_data.py       # 변수 시계열 점검
python step2_build_features.py   # 목표값·설명변수 가공, 사용변수 정리표
python step3_run_models.py       # 기준모형 + 10개 모형 표본외 검증 (약 2분)
python step4_plot_summary.py     # 성과 요약 도표
```

변수별 전처리 명세는 `spec.py`의 `SPEC` 한 곳에 있다.

단위는 %p다. 시험 구간 y의 표준편차는 연도별로 0.93 ~ 1.68이다.

읽는 법

1. **17개 시도 전체로는 어떤 확장 모형도 기준모형을 이기지 못했다.** 가장 나은 Lasso도 RMSE가 1.9% 크고, 차이는 통계적으로 유의하지 않다.
2. **원인의 대부분은 세종이다.** 세종은 Lasso의 RMSE가 3.62로 기준모형(2.48)보다 훨씬 크다. 세종을 채점에서 빼면 PLS·Lasso·Ridge가 기준보다 8 ~ 17% 낫다. 다만 이 차이도 DM 검정으로는 유의하지 않고(p 0.18 ~ 0.33), 결과를 본 뒤에 나눠 본 것이라 확인용으로만 읽어야 한다.
3. **연도별로 엇갈린다.** 확장 모형은 2021년(월세 급등기)에는 기준보다 낫고, 2022년(금리 급등으로 하락 전환)에는 크게 나쁘다. 연도별 값은 `output/03_성과_연도별RMSE.csv`.
4. **규제가 없는 OLS와 비선형 모형이 가장 나쁘다.** 전국 공통 변수 18개는 학습 구간에 서로 다른 시점이 48 ~ 96개뿐이라 과적합되기 쉽다.
5. **직전 1개월 변화율이 가장 큰 개선을 준다.** 기준모형에 이 변수 하나를 더하면 RMSE가 12% 줄고 5개 연도 모두에서 낫다. "한 변수에 한 변환" 원칙 때문에 본 비교에서는 뺐다.
6. 변수 중요도(시험 구간 순열)는 매매가격 6개월 변화, 인구 12개월 변화, 주택시장 소비심리 순이다. `output/03_변수중요도_순열.csv`.

## 한계

- 시험연도가 5개뿐이고 6개월 목표가 매달 겹쳐, 독립적인 관측은 표본 수보다 훨씬 적다.
- 세종(고용률·주택보급률·소비심리)과 제주(소비심리)의 초기 빈칸은 지역 평균으로 채웠다.
- 지역 고정효과와 상관 제거는 내부 검증 겹마다 다시 계산하지 않고 바깥 학습 구간 기준으로 한 번 계산했다.
- DM 검정은 기준모형을 포함하는(중첩) 모형 비교에서는 보수적이다.
- 실거래 건수(V006·V007)는 서울만 값이 있어 뺐다.

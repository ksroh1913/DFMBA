DFMBA 저장소 이관 및 실행 안내_TH_v1
작성일: 2026-10-05

1. 작업 목적과 범위
OneDrive에서 완료한 TH V11·V12 실험을 팀 저장소 구조에 맞춰 복사하였다.
원자료와 기존 팀 코드는 보존하였으며, 이번 작업은 통합 실행 파이프라인을
교체하는 작업이 아니다. 브랜치 생성, Git 등록·커밋·push·PR·merge는 수행하지 않았다.
인증정보(.env)는 읽거나 복사하지 않았으며, 이 실험의 실행에 API 키는 필요 없다.

2. 파일 위치
ml/experiments_TH_v1/TH_v11: 기존 V11 입력, 학습 코드, 원형 결과, 그래프
ml/experiments_TH_v1/TH_v12: 모멘텀을 1개월·6개월 2개로 줄인 V12 비교 실험
ml/run_experiments_TH_v1.py: 저장소 위치에서 실행하는 공통 진입점
ml/export_results_TH_v1.py: 원형 결과를 팀 스타일 한글 결과표로 변환
ml/output/TH_v11, TH_v12: 한글 결과표 및 양식·실행 점검 기록
docs/TH_v11: 기존 V11 보고서와 팀 공유용 Word 문서의 보존본
docs/TH_v12: 기존 V12 실험 안내 자료
ml/experiments_TH_v1/이관기록_TH_v1.json: 복사 파일 및 원본 해시 기록

기존 버전의 내부 상대경로를 유지하여 검증된 학습 코드 자체를 수정하지 않았다.
원형 README와 Word는 당시 실험 설명을 보존한 자료이다. 저장소에서의 실행은
이 안내의 명령을 우선한다. Word 문서를 이번에 새로 작성하거나 갱신한 것은 아니다.
Word 재작성 도구는 이 이관 묶음에 포함하지 않았다.

3. 실행 방법
터미널의 작업 위치를 DFMBA 저장소 최상위 폴더로 설정한다.
Python 3.12 계열의 별도 가상환경 사용을 권장한다.
패키지 버전 목록은 기존 실험에서 검증한 환경을 기록한 것이며, 설치를 이번에
새로 수행하지 않았다. 다른 운영체제·Python 버전의 설치 가능성은 별도 확인한다.

필요 패키지 설치:
python -m pip install -r ml/experiments_TH_v1/TH_v12/requirements_TH_v12.txt

입력·학습 코드의 기존 완료 실험 대비 일치 확인(기본 동작):
python ml/run_experiments_TH_v1.py --version both --stage check

마지막 학습 분기의 재학습 결과 비교(버전별 32회, 총 64회):
python ml/run_experiments_TH_v1.py --version both --stage smoke

한글 결과표만 재생성:
python ml/run_experiments_TH_v1.py --version both --stage export

전체 재학습·분석·한글 결과표 생성:
python ml/run_experiments_TH_v1.py --version v11 --stage all
python ml/run_experiments_TH_v1.py --version v12 --stage all

all 단계는 버전별 1,024회 적합을 포함한다. 기존 결과를 확인하려면 check 또는
export만 사용한다. smoke는 전체 재실험이 아닌 이관 후 실행 일치 점검이다.
review 단계만 실행하는 경우 저장 모델과 model-ready 파일이 먼저 필요하다.
이 파일들은 Git 제외 대상이므로 새로 내려받은 저장소에서는 train을 먼저 실행한다.
--runtime은 필요한 경우 Python 라이브러리 폴더를 지정하는 선택 옵션이다.
인증정보 파일이나 .env 경로를 넣는 옵션이 아니다.

4. 팀 양식과 맞춘 부분
팀의 ml/output 배치를 따르되 TH_v11·TH_v12 하위 폴더로 결과를 분리하였다.
패널 이름을 17시도·서울25구, 과제를 변화율·방향·급등·급락으로 표시하였다.
결과표에서 Linear 명칭은 Y1의 Ridge와 분류 과제의 Logistic으로 구분하였다.
원형 수치와 예측값을 바꾸지 않고 열 이름과 표시를 대응시켰다.
입력의 region, region_code, month(YYYYMM), Y_평가사용가능 등의 메타정보와
기존 Vxxx 식별자를 보존하였다. 파생 특징에는 임의의 새 Master ID를 부여하지 않았다.

결과_요약: 전체 2018~2025 및 주 평가 2021~2025 성능
결과_fold별: 연도별 평가표(실제 재학습 주기가 연간이라는 뜻은 아님)
학습_fold별: 실제 분기 재학습의 학습·시험 범위와 특징 수, 설정
임계값: 연초 학습자료에서 정한 연내 고정 사건 기준
변수선택: 각 학습 시점의 관측률·고유값 수·선택 여부
예측값: 지역·결정월별 정답·예측·진단 점수
모든 파일명에 TH와 버전 표시를 유지하였다.

5. 기존 팀 코드와 다른 분석 정의
Y1: TH 실험에는 6개월 변화율 회귀 평가를 추가하였다.
Y2: 기존 팀의 보합·상승·하락 3분류에서 상승·하락 2분류로 변경하였다.
    실제 변화율이 정확히 0인 행은 Y2에서만 제외하며, 보합 확률을 만들지 않는다.
Y3·Y4: 기존 팀 코드의 상하위 20%와 달리 TH 실험은 상하위 15%를 사용한다.
    연초의 이용 가능한 학습자료에서 임계값을 정하고 해당 연도에는 고정한다.
    임계값 표의 dn은 기존 양식처럼 양의 하락 폭으로 표시한다.
    실제 부호를 포함한 하한은 급락하한_D 열에 따로 기록한다.
재학습: 기존 팀의 연간 방식과 달리 TH는 1·4·7·10월 분기 재학습을 사용한다.
변수선택: 전체기간이 아닌 해당 학습자료 안에서 판단한다.
평가: 해당 기간 관측을 통합한다. 주요 AUC는 동월 지역쌍 비교이며,
    전체기간 통합 AUC·AP는 보조 지표로 구분한다. 기존 연도 평균 AUC와 같지 않다.
모멘텀: V11의 여러 가격 모멘텀에서 V12는 1개월·6개월 2개만 사용한다.
    두 버전 모두 경제·수급 특징을 포함한다. 경제변수 유무 비교 실험은 아니다.

6. 아직 통합하지 않은 부분과 한계
TH 입력은 이전 전처리에서 확정한 넓은 형태의 CSV 스냅샷이다.
기존 processed의 긴 형태 CSV나 자동 선택 Excel 파일을 대신하지 않는다.
따라서 raw 수집부터 이 CSV까지 한 번에 재생성하는 완전한 파이프라인은 아니다.
기존 팀의 최신 Excel 자동 선택에 영향이 없도록 최상위에 새 취합 Excel을 두지 않았다.
기존 ml/run_baseline.py와 ml/build_report_data.py도 수정하지 않았다.
후자는 보합 확률·기존 모형 명칭·SHAP 등을 가정하므로 TH 결과를 그대로 넣을 수 없다.
기존 웹·보고서 데이터와 통합하려면 별도 연결 작업과 검증이 필요하다.
새 SHAP·확률보정·50% 운영경보·API 수집·백엔드는 이번 작업에 추가하지 않았다.
진단 점수를 계산했다는 사실은 운영경보를 도입했다는 의미가 아니다.
이관 일치 검증은 원자료의 정확성이나 모델의 미래 성능을 보증하지 않는다.

7. Git 및 원본 보존
원본 OneDrive 파일은 이동·삭제하지 않았다. 저장소의 기존 팀 입력·코드·결과도
덮어쓰지 않았다. 기존 추적 파일 중 .gitignore만 TH 전용 제외 규칙을 추가하였다.
제외 대상: 인증정보, 라이브러리 런타임, 저장 모델, 재생성 가능한 model-ready 입력,
체크포인트, QA 임시파일, ZIP, 한글 양식의 대용량 중복 예측 CSV.
원형 예측 CSV와 핵심 입력·코드·요약 성능표는 버전별로 보존한다.
중복 한글 예측 CSV는 export 명령으로 다시 생성할 수 있다.
실험 원형 보존과 팀 양식 연결을 분리한 상태이며, 현재 단계는 통합·merge가 아니다.
다음 Git 작업은 변경 파일을 확인한 뒤 별도 브랜치에서 진행한다.
push·PR·merge는 사용자 승인을 받은 후에만 진행한다.

Git 업로드 준비 시 .gitattributes를 추가하여 TH 원형 스냅샷과 보존 문서의
자동 줄바꿈 변환을 비활성화하였다. 이는 Windows/Linux에서 내려받아도
기존 입력·코드 해시 검증이 유지되도록 하기 위한 설정이다.

8. 이번 이관의 실제 검증 결과
V11·V12 각각 32회, 총 64회 마지막 분기 모형을 새 위치에서 다시 적합하였다.
예측값·분류 진단 점수가 기존 저장 결과와 허용 오차 1e-8 이내로 일치하였다.
각 버전의 원형 예측 129,024행을 보존하며 한글 결과표를 생성하였다.
입력·학습 코드의 해시가 기존 완료 실험 기록과 일치하였다.
복사한 197개 파일은 OneDrive 원본과 해시가 일치하였다.
기존 추적 파일 153개 중 .gitignore를 제외한 파일은 모두 기존 해시와 일치하며,
.gitignore 변경도 기존 규칙 삭제 없이 TH 전용 제외 규칙 추가로 확인하였다.
Git 인덱스에 등록된 변경은 없으며 현재 브랜치는 main이다.
저장 모델·재생성 파일·중복 한글 예측 CSV·.env의 Git 제외를 확인하였다.
후보 텍스트에서 비공개 키 파일 형식·GitHub 토큰 패턴을 검사하였다.
이는 모든 종류의 비밀정보를 보장하는 완전한 보안감사는 아니므로 push 전에
최종 변경 목록 및 민감정보 점검을 다시 수행한다.
기록: ml/output/TH_v11·TH_v12/실행점검_TH_v11·TH_v12.json,
      ml/output/TH_v11·TH_v12/양식점검_TH_v11·TH_v12.json,
      docs/이관검증_TH_v1.json.

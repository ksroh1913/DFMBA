5. **저빈도 → 월**: 분기·반기·연간은 공표 시점 이후 최신 공표값을 유지하는 계단 채움 (`impute/build_preprocessed.py:380` `stepfill`). 보간이 아니다 — 설정 파일 V017 주석의 "연간 보간" 은 코드와 다르다(문구 수정 필요).

## 4 정상성 검증

### 4.1 방법 (시트 5·6·6b, 부록 B)

- 주 사양: ADF(상수항, maxlag 12, AIC) + KPSS(상수항, 자동 대역폭, 5% 임계값으로 판정). 판정: ADF 기각 ∧ KPSS 비기각 → I(0); ADF 비기각 ∧ KPSS 기각 → I(1); 둘 다 기각 → 불확정(구조변화·강한 지속성); 둘 다 비기각 → 불확정(검정력 부족).
- 강건성: 추세항 포함(ct), KPSS legacy 대역폭, 주 사양에서 I(0) 가 아닌 계열에 Zivot–Andrews 구조변화 시점.
- 건너뛰기: 상수, 연간 계단(12개월 런) 은 검정 생략, 분기 계단은 분기 부표본, n < 40 은 AR(1)만.
- 전국은 모형창(결정월 2016-01~2025-12, n=120)과 전체 가용 구간 두 창. 패널은 시도별로 검정해 ADF·KPSS 기각 비율, Fisher(Maddala–Wu)·Stouffer 결합 p, 다수 판정, ΔD 의 지역 간 평균상관을 보고. 기준 지역 편차는 월별 합이 0 이라 시도 간 독립 가정이 깨지므로 결합 p 는 참고값이다.
- 주의: 타깃 G{h} 와 12개월 변화·12개월합 입력은 구성상 MA(h−1)·MA(11) 자기상관을 갖는다. 단위근 검정은 이런 겹침 계열에서 보수적(기각이 어려움)이므로 '불확정(검정력 부족)' 이 많이 나오는 것 자체가 입력이 **강하게 지속적**이라는 뜻이다.

### 4.3 함의

이 모형에서 정상성이 문제가 되는 경로는 두 가지다.

1. **첫 창 표준화의 외삽**: 공통 블록은 훈련행 평균·SD 로 표준화된다(`index.py:69-75`). 첫 창(22행, h=6 은 19행)에서 추정한 SD 로 2022~2023년 값을 나누면 금리 Δ12 의 |z| 가 V043 13.2, V059 8.1, V045 6.0, V056 5.9 (2022-10 전후; 시트 2 에서 계산) 가 된다. 절삭이 없으므로(`winsor_sd: null`) 한 변수가 동인 ③·⑥ 지수를 지배한다. 비정상 입력은 훈련 평균에서 체계적으로 멀어지므로 재적합(월별)으로도 완전히 해소되지 않는다.
2. **허위 적합과 부호 불안정**: 22행 창에서 비정상 입력과 (역시 지속적인) G 를 맞추면 추세끼리의 우연한 일치가 계수에 들어간다. ± 부호를 같은 22행의 Spearman 으로 정하므로(`index.py:22-34`) 부호도 불안정하다 — 2018-01 과 2025-12 적합 사이 10/22 가 뒤집혔고, V060 은 ρ = +0.09 로 사실상 잡음이다. 사전 부호도 자료와 어긋나는 것이 있다: 탐색 창에서 V022·V023(착공·준공) 의 공통 성분은 G6 와 +0.54·+0.76 인데 사전 부호는 "−" 다(`analysis/output/plan_v9_eda_변수별.csv`).

v9 의 S1(추세 제외) 은 수준 4열만 뺐고, 남은 수준형 7열과 Δ12·12개월합 입력의 지속성은 다루지 않았다. 타깃 자체가 겹침 변화율이라 어느 정도 지속성은 불가피하지만, **입력 쪽의 I(1) 15열은 Δ12 → Δ1(월 차분) 또는 12개월합 → 월 흐름의 Δ12 같은 추가 차분으로 줄일 수 있고**, 수준형은 `common_outputs: [Δ12]` 설정만으로 전환된다(코드 수정 없음). 다만 차분을 늘리면 h=6 과의 시차 정합·잡음 증가가 따르므로 7장의 순서로 다룬다.

## 5 학습 방법 (무엇을 하는가)

### 5.1 타깃과 사건 (`targets.py:19-52`, `:73-96`)
- 결정월 t 는 t월 말. 마지막 관측 R(t−1). G(i,t,h) = 100·[R(t−1+h)/R(t−1) − 1], 정답은 t+h 월 말 확인. r = G − Ḡ(17개 시도 평균, 모두 있는 달만).
- 급락 G ≤ 100·[0.98^(h/12) − 1] (h=1·3·6: −0.168·−0.504·−1.005%), 급등 ≥ 100·[1.03^(h/12) − 1]. 상태: 직전 h개월 변화가 경계 안이면 '기존 상태'.

### 5.2 전진 평가 (`engine.py`, `split.py`)
- 평가 결정월 2018-01~2025-12 (96개), 사후 확인 ~2026-09. 훈련행은 2016-01 이후 결정월 ≤ T−h → 정답이 확인된 행만 (gap h). 내부 교차검증 `ForwardMonthSplit` 도 gap h, 마지막 12개 결정월.
- 모형 적합(변환기·대체·스케일·계수)은 **매 결정월** 다시 한다. alpha 만 매년 1월 재선택.

### 5.3 모형 (`engine.py:58-224`, `:354-418`; `models.py`)
- 전국 A: `past1·3·6 + V002·V026 6개월%` Ridge. B: A + RMPI공통(6 지수 + 결측표시). C: A + 공통 블록 41열 개별 입력(`IndividualInputs`).
- 보정 구조: y = G − mom1 (mom1 = h·past1). M0 = mom1, M1 = 훈련 잔차 평균, M1′ = mom1 에 절편·기울기 OLS, M2 = Ridge(V002·V026 + RMPI공통 [+ 패널: RMPI지역]), M2+past36, M3 = M2 + 실거래 2열. 최종 예측 = mom1 + 보정.
- 패널: r 은 Ridge(alpha 170 고정) 뒤 같은 달 예측 평균을 빼 보정(17개 시도 완전 횡단면만, `:215-217`); down 은 로지스틱(C = 1/170 고정); 정보군 A/B/Bc/C/B+RT.
- 단순 기준 (`baselines.py`): zero·mom1·mom3·lasth·train_median, 직전 24개월 MAE 최소를 고르는 선택형.

### 5.4 alpha (`engine.py:282-334`)
- cv_min: 1단계 격자 10⁻²~10⁴ 25점 → 최솟점 ±0.5 로그 0.125 간격 → 평균 손실 최소; 최소의 1% 안이면 10 에 가장 가까운 것(`:327-332`); 격자 끝이면 한 자릿수 연장; 폴드 < 4 이면 fallback 10 (`:292-294`; 2018-01 h=6 이 해당). 민감도 fixed 10, 1-SE.
- 실제 선택값(`v9_s1_alpha선택.csv`): B cvmin 이 h=1 에서 0.01~31.6, h=6 에서 0.56~17,783 — 한 자릿수가 아니라 네 자릿수를 오간다.

### 5.5 지표와 추론 (`run_v9_stage6.py:39-92`, `evaluate.py`)
- 손실: 월별 MAE(패널은 같은 달 17개 시도 평균 먼저). 비교: d = L_b − L_a 의 연평균 8개(df 7)·2년 평균 4개(df 3) t-구간과 8차 판정 규칙(`evaluate.py:29-54`), DM 검정은 참고(`run_v9_stage6.py:67-87`).
- 사건: Brier·Brier skill·AP·ROC-AUC·F1(컷오프 = 훈련 사건비율). 경보(④): 훈련 사건비율 ×1·×2 분위 컷오프, 비급락 상태 지역에서 적중률·포착률·동월 지역쌍 AUC·국면 시작 선행시간 (`evaluate.py:163-180`).

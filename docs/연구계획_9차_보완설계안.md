# 아파트 월세 흐름 진단과 급변 예측: 9차 보완 연구 설계안

작성 2026-10-05, 같은 날 독립 검토 1회 반영. 상태: 초안(설계 동결 전). 8차 확정 계획(docs/연구계획_8차_확정본.md)과 그 실행 보고(docs/연구결과_8차계획_실행보고.md)를 전제로, 전국 단위로 취합이 끝난 국토부 실거래 자료(데이터취합_전처리_20261005.xlsx)를 반영해 무엇을 어떻게 보완할지 적는다. 1장의 자료 점검 수치는 analysis/plan_v9_data_audit.py, 4장의 탐색 수치는 analysis/plan_v9_eda.py 가 다시 계산한다(출력 analysis/output/plan_v9_*.csv, plan_v9_eda_요약.txt).

## 0 요지

- 바뀐 것은 실거래 세 열(V006 월세 건수·전체 건수, V007 매매 건수)뿐이다. 17개 시도에서 결측 94.1% → 0.5%(2차 시트)로 채워졌고 2011.01부터 끊김 없이 있다. 나머지 열은 셀 단위로 같다. 행은 2026.10 한 달이 늘었다.
- 실거래 자료에는 세 가지 함정이 있다. ① 최신 1~2개월은 신고 지연으로 건수가 절단돼 있다(자료 추출 5일 뒤 기준 2026.09 는 전년 동월의 0.41~0.83배, 2026.10 은 0.01~0.05배). ② 2021.06 임대차 신고제로 월세 건수가 한 단계 뛰고 그 폭이 지역마다 다르다(2021년 하반기/2020년 하반기 1.14~2.28배, 전세는 1.05~1.57배). ③ 월세 비중은 2012년 0.18~0.47 에서 2025년 0.38~0.69 로 추세적으로 오른다. ②가 가장 까다롭다. 지역별로 다른 영구 이동이라 월내 편차로도 지워지지 않으므로, 12개월 변화형은 경계를 가로지르는 창을 결측으로 두고 수준형은 경계 전후 12개월 편차 차이로 접합한다(1장).
- 탐색 창(결정월 2017.12 이전)에서 실거래 후보의 신호는 약하다. 월내 순위상관(공식 구간 24개월 평균) 은 월세 거래 회전율 0.28, 월세 비중 0.19, 전월세 회전율 0.16, 매매/전월세 비율 0.14 로, 기존 상위 입력(V037 심리 0.61, V032 전세수급 0.46)에 못 미치고 월별 표준편차(0.18~0.32)와 같은 크기다. 채택 근거는 상관이 아니라 ④ 임대시장 동인에 없던 '거래량' 정보라는 사전 논리이며, 기여는 사전 지정 보조 비교(B+실거래 vs B)로 판정한다. 매매 건수(V007)는 부동산원 매매거래현황(V036)과 |ρ| 0.98 로 같은 정보라 넣지 않는다.
- 변수 간 상관이 높은 것을 빼자는 지적은 절반만 맞다. Ridge 와 RMPI(묶음 안 동일 가중 평균)는 상관이 높아도 예측이 망가지지 않지만, |ρ| ≥ 0.95 인 쌍은 같은 정보를 두 번 세어 묶음 가중을 왜곡하고 기여도 해석(SHAP)을 둘로 쪼갠다. 그래서 중복 군집은 대표 하나만 남기고(R2), 공통 블록에서는 시간 추세와 구분되지 않는 수준값을 뺀다(R1). 목표와의 상관이 약하다는 이유로는 빼지 않는다(R3). 탐색 창이 24~61개월뿐이라 그 선택 자체가 과적합이 된다.
- 8차 결과가 남긴 과제는 진단을 바로잡아 반영한다. 8차의 재튜닝 민감도(1-표준오차 규칙)는 A 와 B 모두를 더 나쁘게 했으므로 '고정 alpha 가 A 를 과하게 축소했다'는 해석은 틀렸다. 문제는 A 와 B 가 단기 관성(mom1)을 품지 못하는 사양이다. 9차는 모형이 사전 지정 선택형 단순기준으로부터의 편차를 예측하게 하고(기준 오프셋), alpha 는 수업자료 절차대로 전진 교차검증 최소 손실로 고른다(2장).
- 8차 결과를 보고 바꾸는 항목(오프셋, alpha 선택, 윈저라이즈, 확장 실험 삭제, XGBoost 부록)은 모두 사후 결정이다. 평가 구간(2018.01~2025.12)은 유지하되 9차 판정은 '설계 동결 후 역사적 재검증(2차)' 으로 표기하고, 사전 지정과 사후 변경을 2장 표에 나눠 적는다.

## 3 수업자료(Financial Data Analytics 13a) 절차의 적용

수업자료는 단면 자료(주택 가격)의 절차다. 그대로가 아니라 시계열·패널에 맞게 옮긴다.

| 수업 절차 | 수업에서 한 것 | 8차에서 이미 한 것 | 9차에서 바꾸거나 더하는 것 |
|---|---|---|---|
| Task definition | 문제·타깃·지표·리스크 정의 | 1장 연구 질문·판정 규칙 | 그대로 |
| Data preparation: 분할을 전처리보다 먼저 | train_test_split 뒤 훈련 자료만 정제 | 시간 분할(최초 훈련 끝 2017.12), 전진 평가 | 그대로. 변수 탐색도 2017.12 이전 자료로 제한(plan_v9_eda) |
| Data exploration: shape·info·describe, 프로파일링, 타깃과의 관계, 쌍별 상관 | sweetviz/ydata 보고서 → TAX(타깃의 함수)·GROSS_AREA(LIVING_AREA 와 중복) 제외 | 변수표·관측률·마스킹 기록(2단계), 묶음 안 상관(stage4_상관중복) | 변수별 목표 상관(공통·지역, h=1·3·6, 두 창), 시간 추세 상관, 블록 전체 쌍별 |ρ| ≥ 0.90 목록과 ≥ 0.95 군집 → 대표 선정 규칙(4장). 타깃 유도 변수 점검: V004 전월세전환율은 월세·보증금 가격에서 계산된 값이라 TAX 와 비슷한 성격이나 t−1 까지의 값만 쓰므로 누수는 아니고 유지. 공통 블록에서는 수준값을 뺀다(R1) |
| Variable type selection | 수치/순서/명목 분류, 파생 변수(비율) | 변환 규칙표(2장) | 실거래 파생 4개(월세 비중, 월세 회전율, 전월세 회전율, 매매/전월세 비율) |
| Preprocessing: Light/Moderate/Heavy 파이프라인 | 결측 대체·스케일·IQR 클리퍼·다항·빈도 인코딩 | ColumnTransformer 기반 RMPI(⑤~⑩) | ±5σ 윈저라이즈 추가. KNN 대체·다항 특성은 쓰지 않음(시계열 누수·선형 주 모형과 맞지 않음) |

## 6 실행 단계와 예상 비용

8차의 7단계 그대로 돌린다. 1단계(설정 동결·점검) → 2단계(자료 진단: 실거래 열 추가, 절단·단절·접합 기록) → 3단계(흐름 진단: 월세 비중·회전율 그림 1장 추가) → 4단계(지수 구축: R1·R2 적용 뒤 구성명세, 상관 중복표 재계산) → 5단계(파이프라인 점검: 과거 절단 불변 항목에 튜닝·선별·접합 계수 포함) → 6단계(예측 평가) → 7단계(해석: 동인 제거에 실거래 묶음 추가, XGBoost 부록, 서울 구 보조).

8차 실행 당시 세션 기록(보고서에는 없음)으로 6단계 45분, 7단계 26분이었다. 9차는 전국 중첩 튜닝(1월마다 2단계 격자 34점 × 12폴드)과 새로 넣는 패널 튜닝(Ridge 는 닫힌 해라 가볍고, 로지스틱 C 탐색이 대부분)을 더해 6단계 약 1.5~2시간, 7단계 약 40분으로 본다(XGBoost 부록 제외 시 7단계 30분).

5. 매매 건수는 V036 유지, V007 은 쓰지 않음(권고). V007 을 쓰려면 V036 을 빼야 한다.
6. XGBoost 부록(약 10~15분 추가): 포함(권고, 수업자료 모형과의 대응).

위 6개가 정해지면 config/plan_v9_settings.yaml 과 analysis/check_settings.py 를 고쳐 1단계로 동결하고, 그 뒤 2~7단계를 돌린다.

# 아파트 월세 흐름 진단과 급변 예측: 9차 보완 연구 설계안

작성 2026-10-05. 상태: 초안(설계 동결 전). 8차 확정 계획(docs/연구계획_8차_확정본.md)과 그 실행 보고(docs/연구결과_8차계획_실행보고.md)를 전제로, 전국 단위로 취합이 끝난 국토부 실거래 자료(데이터취합_전처리_20261005.xlsx)를 반영해 무엇을 어떻게 보완할지 적는다. 설계 근거 수치는 analysis/plan_v9_eda.py 가 다시 계산한다(출력 analysis/output/plan_v9_eda_*.csv, _요약.txt).

## 0 요지

- 바뀐 것은 실거래 세 열(V006 월세 건수·전체 건수, V007 매매 건수)뿐이다. 17개 시도에서 결측 94.1% → 0.5%(2차 시트)로 채워졌고, 2011.01부터 끊김 없이 있다. 나머지 열은 셀 단위로 같다. 행은 2026.10 한 달이 늘었다.
- 실거래 자료에는 세 가지 함정이 있다. ① 최신 1~2개월은 신고 지연으로 건수가 절단돼 있다(2026.09 는 전년 동월의 0.4~0.8배, 2026.10 은 0.01~0.05배). ② 2021.06 임대차 신고제로 월세 건수가 한 단계 뛴다(2021년 하반기 / 2020년 하반기 = 1.14~2.28배, 전세는 1.05~1.57배). ③ 월세 비중은 2012년 0.18~0.47 에서 2025년 0.38~0.69 로 추세적으로 오른다. 그래서 수준값은 월내 편차(지역 블록)로만 쓰고, 12개월 변화는 신고제 경계를 가로지르는 12개월을 결측으로 두며, 최신 2개월은 쓰지 않는다.
- 탐색 창(결정월 2017.12 이전)에서 실거래 후보의 신호는 보통 수준이다. 지역 블록에서 월세 거래 회전율(월세 건수 12개월합/천세대)의 월내 순위상관 0.28, 월세 비중 0.19, 매매/전월세 비율 0.14~0.44. 기존 상위 입력(V037 심리 0.61, V032 전세수급 0.46)보다 낮지만 ④ 임대시장 동인에 없던 '거래량' 정보다. 매매 건수(V007)는 부동산원 매매거래현황(V036)과 |ρ| 0.98로 같은 정보라 넣지 않는다.
- 변수 간 상관이 높은 것을 빼자는 지적은 절반만 맞다. Ridge 와 RMPI(묶음 안 동일 가중 평균)는 상관이 높아도 예측이 망가지지 않지만, |ρ| ≥ 0.95 인 쌍은 같은 정보를 두 번 세어 묶음 가중을 왜곡하고 기여도 해석(SHAP)을 둘로 쪼갠다. 그래서 중복 군집은 대표 하나만 남기고, 공통 블록에서는 시간 추세와 구분되지 않는 수준값을 뺀다. 목표와의 상관이 약하다는 이유로 변수를 빼지는 않는다(탐색 창이 24~61개월뿐이라 그 선택 자체가 과적합이 된다).
- 8차 결과가 남긴 과제도 함께 고친다. 고정 alpha(전국 10)가 A 정보군을 과하게 축소해 B 의 우위가 부풀려졌으므로, 수업자료의 절차대로 훈련 자료 안의 전진 교차검증으로 alpha 를 단계적으로 고르는 방식을 주 분석으로 올린다. A 에 단순기준(모멘텀) 항을 넣어 모형이 단순기준을 품게 한다.
- 평가 구간(2018.01~2025.12, 96개 결정월)과 판정 규칙은 유지한다. 다만 이 구간의 결과를 이미 보았으므로 9차도 '설계 동결 후 역사적 재검증' 이고, 변수 선별은 2017.12 이전 자료로만 했다는 점을 보고서에 명시한다.

## 3 수업자료(Financial Data Analytics 13a) 절차의 적용

수업자료는 단면 자료(주택 가격)의 절차다. 그대로가 아니라 시계열·패널에 맞게 옮긴다.

| 수업 절차 | 수업에서 한 것 | 8차에서 이미 한 것 | 9차에서 바꾸거나 더하는 것 |
|---|---|---|---|
| Task definition | 문제·타깃·지표·리스크 정의 | 1장 연구 질문·판정 규칙 | 그대로 |
| Data preparation: 분할을 전처리보다 먼저 | train_test_split 뒤 훈련 자료만 정제 | 시간 분할(최초 훈련 끝 2017.12), 전진 평가 | 그대로. 변수 탐색도 2017.12 이전 자료로 제한(plan_v9_eda) |
| Data exploration: shape·info·describe, 프로파일링, 타깃과의 관계, 쌍별 상관 | sweetviz/ydata 보고서 → TAX(타깃의 함수)·GROSS_AREA(LIVING_AREA 와 중복) 제외 | 변수표·관측률·마스킹 기록(2단계), 묶음 안 상관(stage4_상관중복) | 변수별 목표 상관(공통·지역, h=1·3·6, 두 창), 시간 추세 상관, 블록 전체 쌍별 |ρ| ≥ 0.90 목록과 ≥ 0.95 군집 → 대표 선정 규칙(4장). 타깃 유도 변수 점검: V004 전월세전환율은 월세·보증금 가격에서 계산된 값이라 TAX 와 비슷한 성격이나, t−1 까지의 값만 쓰므로 누수는 아니고 유지. 다만 공통 블록에서는 수준값을 뺀다 |
| Variable type selection | 수치/순서/명목 분류, 파생 변수(비율) | 변환 규칙표(2장) | 실거래 파생 비율 3개(월세 비중, 월세 회전율, 매매/전월세 비율) |
| Preprocessing: Light/Moderate/Heavy 파이프라인 | 결측 대체·스케일·IQR 클리퍼·다항·빈도 인코딩 | ColumnTransformer 기반 RMPI(⑤~⑩) | ±5σ 윈저라이즈 추가. KNN 대체·다항 특성은 쓰지 않음(시계열 누수·선형 주 모형과 맞지 않음) |
| Model training: Stage 0 기준 → Stage 1 넓은 무작위 탐색 → 2·3 좁힘 → 4 격자, 교차검증 점수로 선택, 과적합 비율·불안정 비율 보고 | KFold(shuffle) 5겹 | 고정 alpha(주), 매년 재튜닝(민감도) | 전진 교차검증(ForwardMonthSplit, 검증 12개월)으로 Stage 1 넓은 격자(10^-2~10^4, 25점) → Stage 2 최적점 주변 ±1 로그단위 9점. Ridge 는 비용이 작아 두 단계면 충분. 훈련/검증 손실 비율(과적합 비율)과 검증 손실 표준편차(불안정 비율)를 연도별로 기록. shuffle KFold 는 시계열에 쓰지 않음 |
| 여러 모형 비교(선형·Ridge·Lasso·ElasticNet·KNN·SVR·트리·XGBoost) | 검증 점수 최고 모형 선택 | Ridge 주, ET 보조, 부록 추가 모형 | 모형 선택은 하지 않음(사전 지정 Ridge). 부록에 XGBoost 를 같은 전진 교차검증·2단계 탐색으로 h=6 에만 추가 |
| Model testing: 최고 모형을 테스트 자료에 한 번 | 검증–테스트 격차 보고 | 2018~2025 전진 평가, 판정 규칙 | 그대로. 변수 선별·튜닝은 모두 각 결정월의 훈련 자료 안에서 끝남을 5단계 점검에 항목으로 추가 |

## 4 변수 탐색 결과 (analysis/plan_v9_eda.py, 탐색 창 결정월 ≤ 2017.12)

두 창을 쓴다. (가) 공식 지수 목표: 정답 확인 ≤ 2017.12 → 공통 24개월, 지역 408행(2016~2017). (나) 참고: 구지수 연결 계열(2015.06 이전은 서울·부산·대구·인천·광주·대전·울산·경기 8개 시도만 있음) 8개 시도 평균과 그 편차, 2012.07~2017 → 공통 47~61개월. 2018~2025 의 목표값은 쓰지 않았다.

### 4.1 목표와의 관계

- 공통 블록에서 (가) 창의 |ρ| 0.9 안팎은 대부분 추세 때문이다. 시간과의 Spearman 이 |0.95| 를 넘는 수준값(V011c 20~39세 비중 −1.00, V004 전환율 −0.99, V072 보급률 0.99, V003 전세가율 0.95, 월세 회전율 0.98)은 (나) 창으로 늘리면 |ρ| 가 0.13~0.33 으로 떨어진다. 두 창에서 모두 |ρ| ≥ 0.5 인 공통 입력: 인구·세대·순이동 12개월 변화(0.82~0.93), V015·V017 Δ12(0.84, n=19), V023 준공(0.76/0.82)·V022 착공(0.54/0.58), V036 매매거래(0.62/0.70), V035 거래(0.60/0.77), V050 지역대출(0.89/0.74), V031 매매수급(0.74/0.49), V044·V045 금리 Δ12(−0.61~−0.89), V070 수출(−0.61/−0.57), V057 전세자금금리(−0.67/−0.74, n=17).
- 지역 블록(월내 순위상관, (나) 창 h=6): V037 심리 0.61, V032 전세수급 0.46, V031 0.36, V023 준공 −0.37, V050 −0.27, V072 −0.26, V021 인허가 −0.25, V013·V015·V017 Δ12 0.24~0.27, V011c Δ12 0.21. CSI(0.02)·V004(0.09)·V003(0.13)·V036(0.12)은 지역 블록에서 약하다.
- 부호: 공급 흐름(V022 착공·V023 준공)은 공통 블록에서 +, 지역 블록에서 − 다. 건설이 많은 시기가 오르는 국면과 겹치고, 같은 달 안에서는 공급이 많은 지역이 덜 오른다. 8차는 사전 부호 '−' 를 두 블록에 똑같이 강제했다. 9차는 사전 부호를 지역 블록의 기본값으로만 쓰고, 공통 블록 부호는 훈련 자료의 Spearman 으로 정한다(|ρ| < 0.1 이면 사전 부호).

| 규칙 | 적용 |
|---|---|
| R1 공통 블록은 수준형 입력을 뺀다(level_and_d12 는 Δ12 만, level 전용 지수 V005·V031·V032·V037·CSI·V060 은 정상 계열이라 유지) | 공통 5개 군집 {V003·V004·V011c·V072 수준, 월세 회전율} 해소 |
| R2 같은 블록에서 |ρ| ≥ 0.95 군집은 대표 하나만 남긴다. 대표는 ① 관측 시작이 이른 것 ② 개정 위험이 없는 것 ③ 측정이 더 직접적인 것 순 | 공통 {V009, V012} → V012 순이동(이동이 임차 수요에 직접). 공통 {V010, V011a} → V010 세대수. 공통 {V043 기준금리, V044 CD} → V043(정책 변수, 시장금리는 V045 가 대표). 지역 {V009, V012} → V012. 지역 {V036, RT 매매 회전율} → V036(신고일 기준이라 절단·개정 위험이 없고 8차와 이어짐) |
| R3 목표와의 상관이 약하다는 이유로는 빼지 않는다 | 탐색 창이 짧아 선택이 곧 과적합. 약한 입력은 Ridge 축소에 맡기고, 동인 제거 실험(7단계)으로 사후 보고 |
| R4 0.90 ≤ |ρ| < 0.95 는 그대로 두되 같은 하위묶음이면 묶음 평균이 흡수 | V003 Δ12~V004 Δ12 0.94 등 |

V009(주민등록인구 로그Δ12)는 두 블록에서 모두 대표에 밀려 빠진다. V011a·V011b(20대·30대 인구)는 지역 블록에 남는다.

## 6 실행 단계와 예상 비용

8차의 7단계 그대로 돌린다. 1단계(설정 동결·점검) → 2단계(자료 진단: 실거래 열 추가, 절단·단절 마스킹 기록) → 3단계(흐름 진단: 월세 비중·회전율 그림 1장 추가) → 4단계(지수 구축: R1·R2 적용 뒤 구성명세, 상관 중복표 재계산) → 5단계(파이프라인 점검: 과거 절단 불변 항목에 튜닝·선별 포함) → 6단계(예측 평가) → 7단계(해석: 동인 제거에 실거래 묶음 추가, XGBoost 부록, 서울 구 보조).

계산 시간은 8차(6단계 45분, 7단계 26분)에 중첩 튜닝이 더해져 6단계 약 1.5시간, 7단계 약 40분으로 본다(XGBoost 부록 제외 시 7단계 30분).

## 7 결정이 필요한 항목

1. 평가 구간: 2018.01~2025.12 유지(권고). 2020 년 이후로 줄이면 결정월 72개로 판정 검정력이 더 떨어진다.
2. 공통 블록 수준형 제외(R1)와 공통 블록 부호의 자료 결정: 적용(권고).
3. 매매 건수는 V036 유지, V007 은 쓰지 않음(권고). V007 을 쓰려면 V036 을 빼야 한다.
4. 주 분석 alpha 를 중첩 튜닝으로 바꾸는 것: 적용(권고). 8차와의 비교 가능성은 고정값 민감도로 유지.
5. XGBoost 부록(약 10~15분 추가): 포함(권고, 수업자료 모형과의 대응).
6. 최신 2개월 절단은 고정 2개월(권고). 비율 기준(예: 전년 동월의 80% 미만)은 실제 변동과 구분이 안 된다.

위 6개가 정해지면 config/plan_v9_settings.yaml 과 analysis/check_settings.py 를 고쳐 1단계로 동결하고, 그 뒤 2~7단계를 돌린다.

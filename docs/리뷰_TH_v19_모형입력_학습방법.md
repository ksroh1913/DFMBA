작성 2026-10-09. 대상 `experiment_TH` 브랜치(커밋 e8c294a, 2026-10-08) `ml/experiments_TH_v1/TH_v19/`.
근거 산출물 `analysis/output/review_TH_v19_입력변수.xlsx` (생성 `analysis/review_th_v19_inputs.py`; TH 브랜치의 특징 코드·입력·예측 파일을 그 커밋에서 내려받아 그대로 돌린 것).
코드 위치는 `파일:줄` 로 적는다. 성능 수치는 TH_v19 가 저장한 `eval_TH_v19/*.csv` 와 예측 파일에서 그대로 계산했다.

## 0 요지

- **무엇을 학습했나**: 17개 시도(2011-01~2026-09) 패널과 서울 25개 구 패널. 타깃은 6개월 경로 — Y1 `g` = 100·[R(t+5)/R(t−1) − 1](회귀), Y3 급등 = 경로 최대 > +1.0%p, Y4 급락 = 경로 최소 < −1.0%p(분류). 입력은 **전처리 워크북의 `2차_공표시점반영` 시트와 값이 100% 일치하는 CSV**(`TH_v11/input_TH_v11/`)에서 만든 특징 **121개(V18) / 241개(V19a) / 235개(V19b)** + 월세 모멘텀 5개 + 지역 더미 17개. 관측률 70% 필터 뒤 실제 입력은 시도 기준 116~120 / 206~216 / 200~210열.
- **어떻게 학습했나**: 분기(1·4·7·10월) 확장창 재학습 2018~2025, 정답이 확인된 행만 학습(month ≤ origin−6), 각 시점은 다음 3개월을 예측. 모형 4종(Ridge/Logistic, RF, ET, XGBoost) 하이퍼파라미터 고정, seed 42, 튜닝 없음. 클래스 가중치 없음(V18), 경보 컷오프 30%.
- **V19 의 변경**: 거시 변수에 3·6개월 변화를 추가(V19a), 금리 수준 열 6개 제외(V19b). 2022~23 하락기 끝의 '헛경보'를 보고 설계한 것이며 README 가 그렇게 밝힌다. 결론은 "주 모형은 V18 유지, V19 는 진단 근거".
- **리뷰 판단**: 시점 처리(공표 시차·정답 확인·분할)는 깨끗하다. 문제는 (1) **입력 차원**: 첫 학습창 425행(17시도×25개월, 6개월 겹침 타깃)에 200~216열, (2) **특징의 질**: 선택된 경제 특징 180개 중 I(0) 24개뿐, 연·분기·5년 계단 계열에 3·6·12개월 변화를 씌운 정보 없는 열 28개, 수준형 비정상 열 8개(CPI·KOSPI·임금지수 수준 등), 중복 열 다수, (3) **단순 기준 대비 이득이 작거나 없음**: 시도 Y1 2021~25 에서 RF·XGB 가 mom1 보다 9% 낫지만 2018~25 전체로는 네 모형 모두 mom1 보다 7~12% 나쁘고 방향 적중률은 mom1 과 같다, (4) **재현 불가**: V18 기준값과 평가 함수를 담은 `TH_v16` 이 브랜치에 없다, (5) 서울 급락(Y4)은 PR-AUC 0.05~0.17 로 사건비율(0.058) 수준 — 작동하지 않는다.

### 1.2 타깃 (`features_TH_v19.py:33-41`)
- R(t−1) 기준 6개월 경로 path_h = 100·[R(t−1+h)/R(t−1) − 1], h=1..6. `g` = path_6, `U` = max, `D` = min.
- Y3 = U > +1.0, Y4 = D < −1.0 (`train_TH_v19.py:29, 39-41`). 연율이 아닌 6개월 안 어느 시점이든 ±1%p 를 넘으면 사건. 2021~25 시도 사건비율 Y3 36.7%, Y4 9.8%; 서울 46.7%, 5.8%.
- KS 와의 차이: KS 는 h=6 누적 G6 ≤ −1.005%(연율 −2%). TH 는 경로 최소라 사건이 더 많고 정의가 느슨하다.

### 2.3 변수 구성의 문제
1. **차원**: 2018-01 학습창은 17시도 × 25개월 = 425행인데 입력이 200~216열(V19)이다. 6개월 겹침 타깃이라 독립 정보는 시도당 4~5개 수준. 트리는 `min_samples_leaf=8`·`max_depth=10` 으로 버티지만 Ridge(alpha 100 고정)는 과적합 영역이다 — 시도 Y1 Linear MAE 0.92 (RF 0.72) 와 급등 Linear 의 큰 악화가 그 증상이다.
2. **계단 계열에 변화율**: V015·V017(연간), V047·V049·V060·V074(분기), V072 총조사(5년·"계단 50개월")에 3·6·12개월 변화를 씌우면 대부분의 달이 0 이고 공표 달에만 값이 튀는 열이 된다. 선택된 경제 특징 180개 중 **28개가 이런 계단 계열**(xlsx 시트 4 '생략사유'). V19a 의 추가분 120개 중 상당수가 여기에 해당한다.
3. **수준형 비정상 열**: `V048 소비자물가지수|수준`, `V064 KOSPI|수준`, `V049 임금지수|수준`, `V003 전세가율|수준`, `V004 전환율|수준`, `V011 20-39세비중|수준`, `V013 고용률|수준`, `V060 대출태도|수준` 이 시도 다수에서 I(1). 추세 변수가 수준으로 들어가면 트리는 외삽을 못 하고 선형은 외삽을 크게 한다(TH 가 스스로 적은 "2022 금리 급등 외삽 문제"가 이것이다).
4. **중복**: V069 가계대출·주택관련대출, V035·V036 동호수·면적, V072 세 형태, V015·V017 천원·전국대비, V043·V044·V045 세 금리, CSI 3개 — 같은 정보가 2~4열씩 들어간다. 트리의 `max_features=0.5` 가 중복에 비교적 둔감하지만 변수 중요도 해석은 분산된다.
5. **전국 변수의 복제**: 거시·금리 변수 ~25개(V19 기준 ~75열)는 17개 시도에 같은 값이다. 지역 더미와 함께 쓰면 "시점 고정효과 + 지역 고정효과" 와 거의 같아, 시도 간 차이를 설명하는 데는 기여하지 않는다. 서울 표는 `서울_` 접두 10열도 25개 구에 복제된다.
6. KS 와 달리 **기준 지역 평균·월내 편차 분해, 표준화 창, 부호 규칙이 없다** — 그래서 KS 의 부호 반전·첫 창 표준화 문제는 없다. 대신 트리 모형이 원값의 수준을 그대로 분기 기준으로 쓴다.

## 3 모형과 학습 방법 (`train_TH_v19.py`)

| 항목 | 내용 | 위치 |
|---|---|---|
| 분할 | 학습시점 origin = 2018~2025 매 1·4·7·10월(32회). 학습행 = month ≤ origin−6 이고 label_available(=month+6) ≤ origin. 시험행 = origin~origin+2 (3개월). 단언문으로 정답 시점 < 시험 시작 확인 | `:68-70`, `features:94-95` |
| 변수 선택 | 학습행 안에서 관측률 ≥ 0.7·비상수 (시점마다 다시) | `:71` |
| 설계행렬 | 선택 특징 + 지역 원핫 (`matrix`) | `features:102-104` |
| Linear | `SimpleImputer(median, add_indicator)` → `StandardScaler` → `Ridge(alpha=100)` / `LogisticRegression(C=0.1)` | `:45-47` |
| RF·ET | 중앙값 대체 → 128그루, `min_samples_leaf 8`, `max_features 0.5`, `max_depth 10` | `:48-51` |
| XGBoost | 128그루, `max_depth 2`, `lr 0.06`, `min_child_weight 3`, `reg_lambda 5`, `subsample·colsample 0.8` | `:52-54` |
| 분류 자격 | 학습 사건 ≥ 30 이고 사건 지역 ≥ 3 아니면 그 시점 건너뜀; 단일 계급이면 `DummyClassifier(prior)` | `:30, 75, 82` |
| 가중치 | 없음(V18 결정). 확률은 그대로, 경보 = 확률 ≥ 0.3 | README, `eval:93` |
| 기록 | 입력·코드 해시, 패키지 버전, 행 수 manifest | `:93-95` |

평가(`eval_TH_v19.py`): 주 기간 2021~2025(보조 2018~2025). Y1 은 MAE·방향 Macro F1, Y3/Y4 는 PR-AUC·BSS(기준 = 그 분기 학습 사건비율)·30% 경보 F1. **V18 대비 차이**를 월 단위 6개월 블록 부트스트랩 1,000회의 95% 구간으로 ✅/❌/△ 판정. 하락기 진단은 2018.07~2020.06, 2022.01~2023.12 의 월별 경보 수와 '후반 헛경보'.

### 3.1 맞게 된 것
- 정답 확인 시점 기준 분할과 단언문, 공표 시차 반영 입력, 학습행 전용 변수 선택·대체·표준화 — **누수 없음**.
- 하이퍼파라미터 고정·튜닝 없음, 시험 자료로 고른 것이 없음(V11 `prespecified_design` 부터 유지).
- 입력·코드 해시와 패키지 버전 기록.
- V19 README 가 "2023년을 보고 설계했으므로 2022~23 개선은 예상된 결과" 라고 스스로 적음.

|---|---|---|---|

## 4 KS(9차)와의 비교 관점

| | KS 9차 (RMPI) | TH_v19 |
|---|---|---|
| 입력 | 41열을 6개 동인 지수로 압축, 기준지역 평균·월내 편차 분해, 훈련창 표준화·부호 | 121~241열 원변수 변환을 그대로, 지역 더미 |
| 모형 | Ridge, alpha 전진 CV | Ridge/Logistic 고정 + RF·ET·XGB 고정 |
| 타깃 | G1·G3·G6 누적, 급락 연율 −2% | 6개월 경로 g·U·D, ±1%p |
| 재학습 | 매월, alpha 1월 | 분기 |
| 단순 기준 | mom1 대비 보정 구조가 주 분석 | mom1 열은 있으나 보고 안 함 |
| 공통 약점 | 입력 지속성(I(0) 소수), 같은 평가 창 반복, 2022 금리 충격 외삽, 서울 구 효과 없음 | 같음 |

두 실험 모두 "경제 변수가 mom1(최근 추세 연장)을 얼마나 넘어서는가" 가 핵심 질문인데, TH 는 h=6 에서 2021~25 한정 약 9%, KS 는 h=1 에서만 19%(2023년 집중) — **어느 쪽도 기간 전체에서 안정적으로 넘지 못한다.**

## 5 권고

1. **TH_v16(및 V13~V17) 산출물·코드를 브랜치에 넣거나, `eval_TH_v19.py` 가 V18 기준을 `TH_v18/output_TH_v18_full` 과 V16 Y1 예측 사본에서 읽도록 바꿔 재현 가능하게** 할 것.
2. Y1 표에 **mom1·0 예측 기준**을 같은 행으로 넣고 "모형/mom1" 비율을 주 지표로. 2018~25 에서 기준에 지는 사실을 보고서에 명시.
3. 특징 정리: 계단 계열(연·분기·5년)은 변화율을 만들지 말고 수준 1열만(또는 제외); 수준형 비정상 열 8개는 Δ12 만; 중복 열은 1개씩; 전국 변수는 시도 간 변동이 없으므로 시점 고정효과로 대체하는 변형을 비교. 목표: 첫 창 425행에 입력 50열 이하.
4. 사건 정의를 KS 와 맞추거나(연율 기준) 최소한 Y3 사건비율이 40% 를 넘지 않게 경계 상향. 서울 Y4 는 사건이 너무 적어 평가에서 빼거나 권역 단위로.
5. 하락기 해제 신호(금리 3개월 변화)는 README 의 제안대로 **사전 지정 후 2026년 전향 검증**으로만 채택.

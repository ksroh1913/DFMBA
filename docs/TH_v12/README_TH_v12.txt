DFMBA TH v12 — 모멘텀 두 개 축소 비교 실험

1. 변경 범위
V11과 동일한 입력자료·경제변수·학습기간·정답·모형 설정을 사용합니다.
최근 1개월 및 6개월 월세지수 변화율만 가격모멘텀 후보로 유지합니다.
3개월·12개월 변화율, 3개월 가속도, 서울 상대 6개월 변화율은 제외합니다.
호환 비교를 위해 유지한 특징의 열 이름 M10_은 변경하지 않았습니다.
이는 1개월 전·6개월 전의 지수 수준을 넣는 실험이 아닙니다.

2. 유지사항
Y1 향후 6개월 변화율 / Y2 상승·하락 / Y3·Y4 연초 과거 상하위 15% 경로 사건.
Ridge/Logistic, Random Forest, Extra Trees, XGBoost 네 모형.
분기 재학습 확장창, 알려진 정답만 학습, 학습창 내 관측률 70%·비상수 선택.
서울 경제변수 축소 없음. 별도 50% 운영 경보 없음.
시험 2018~2025년, 주 비교 2021~2025년. 지표 집계는 V11과 동일합니다.

3. 실행
Python 3.12에서 검증합니다.
python -m pip install -r requirements_TH_v12.txt
python ml/train_simple_TH_v12.py
python analysis/review_simple_TH_v12.py
python analysis/summarize_experiment_TH_v12.py
API 키와 .env는 필요하지 않고 읽지 않습니다.
DFMBA_RUNTIME은 선택적인 로컬 라이브러리 경로입니다.
V11 인접 폴더가 없으면 대조 검증만 건너뛰며 자체 학습·검증은 실행됩니다.
비교 요약 생성에는 보존한 V11 결과표 두 개를 사용하므로 이전 작업폴더가 필요하지 않습니다.
이번 실험은 Word 보고서를 다시 작성하는 작업은 아닙니다.

4. 재현성과 공유
analysis/output_TH_v12에 학습·평가·대조 결과, 선택 특징, 해시와 저장 모형을 기록합니다.
팀 DFMBA 저장소·원자료·V11을 수정하지 않습니다.
반복 확인한 시험기간의 비교 실험이며 새로운 미관측 최종 검증은 아닙니다.
행 수는 독립 표본 수가 아닙니다. 지역·인접 월의 경로가 중첩됩니다.
외부의 출처가 불명확한 joblib 파일은 열지 마십시오.

# TH_v18: 클래스 가중치 처리 방식 비교 (2026-10-06)

로컬 전용입니다(`.git/info/exclude`).

## 비교한 세 방식 (Y3 급등·Y4 급락, 전체·모멘텀 모형)

| 방식 | 내용 | 재학습 |
|---|---|---|
| **A. 가중치 없음** | 클래스 가중치 없이 재학습<br>(로지스틱·RF·ET의 `class_weight`, XGB의 `scale_pos_weight` 제거) | ✅ `ml/train_TH_v18.py` |
| B. 가중치 + 공식 되돌리기 | V16 확률의 odds를 그 분기 가중치 w = (1−r)/r로 나눔 (r = 학습 사건비율).<br>로지스틱은 정확한 보정이고, 트리는 근사 | – |
| C. 가중치 + Platt 보정 | V17 보정 확률 | – |
| (참고) 가중치 원래 확률 | V16 확률 그대로 | – |

나머지 설계는 V16과 같습니다(변수, 하이퍼파라미터, 분기 재학습, 사건 기준 ±1.0%p, 최소 사례 규칙).

- **'balanced' 가중치:** 매 분기 학습 자료에서 (비사건 수 ÷ 사건 수)로 자동 계산합니다. 예를 들어 2022.07 시도 급락은 1,183 ÷ 160 ≈ 7.4배입니다.

## 평가
- **순위 실력:** PR-AUC로 봅니다. 2021~25 전체이고, A와 가중치 있음을 비교합니다. B·C는 순위를 바꾸지 않습니다.
- **확률 정확도와 경보:** C까지 값이 있는 같은 지역·월만 비교합니다.
  - Brier, BSS
  - **BSS 기준:** 그 분기 학습 사건비율을 그대로 쓰는 예측입니다. V17은 '보정 자료의 과거 비율'을 기준으로 써서, V17의 BSS 수치와는 직접 비교할 수 없습니다.
  - 30%·50% 경보의 F1을 '항상 사건'과 비교합니다.
- **서울 급락:** C가 2023.04부터만 가능해 평가 구간에 급락이 0건입니다. 확률·경보 평가에서 제외했습니다.

## 결과 (2021~2025, 전체 모형)

### 1. 가중치를 빼도 순위 실력은 유지되나 (PR-AUC: 가중치 없음 vs 있음)

| | Linear | Random Forest | Extra Trees | XGBoost |
|---|---|---|---|---|
| 시도 급등 | 0.647 vs 0.663 △ | 0.803 vs 0.774 △ | 0.831 vs 0.806 △ | 0.798 vs 0.794 △ |
| 시도 급락 | 0.534 vs 0.532 △ | **0.601 vs 0.400 ✅** | 0.591 vs 0.527 △ | 0.522 vs 0.455 △ |
| 서울 급등 | 0.781 vs 0.774 △ | 0.720 vs 0.757 △ | 0.691 vs 0.723 △ | 0.778 vs 0.762 △ |
| 서울 급락 | 0.171 vs 0.518 ❌ | 0.099 vs 0.086 △ | 0.084 vs 0.095 △ | 0.060 vs 0.049 ✅ |

- 전체 모형은 가중치를 빼도 **순위 실력이 떨어지지 않습니다.** 시도 급락 RF는 오히려 올랐습니다.
- 모멘텀 모형의 시도 급등은 3개가 ❌로 떨어졌습니다(−0.04~−0.05).
- 서울 급락 Linear의 큰 하락은 하락 국면이 1회뿐인 표본의 결과입니다.

### 2. 확률 정확도 (BSS, 높을수록 좋음)

| 모형 | 시도 급등<br>A / B / C / 원래 | 시도 급락<br>A / B / C / 원래 | 서울 급등<br>A / B / C / 원래 |
|---|---|---|---|
| Extra Trees | **0.36** / 0.14 / 0.28 / 0.37 | 0.23 / 0.26 / 0.11 / 0.05 | 0.34 / 0.14 / 0.28 / 0.42 |
| Random Forest | **0.31** / 0.07 / 0.25 / 0.34 | **0.29** / 0.14 / 0.16 / 0.12 | 0.39 / 0.11 / 0.27 / 0.43 |
| XGBoost | 0.20 / 0.12 / 0.26 / 0.29 | 0.19 / 0.21 / 0.20 / −0.09 | 0.38 / 0.34 / 0.40 / **0.50** |
| Linear | 0.08 / 0.06 / −0.07 / −0.06 | −0.81 / −0.84 / −0.43 / −1.15 | 0.37 / 0.36 / 0.29 / 0.40 |

- **B(공식)는 트리 모형에서 확률을 지나치게 낮춥니다.** 트리의 확률은 로지스틱과 구조가 달라 공식이 맞지 않습니다.
- **A(가중치 없음)는 대부분 안정적으로 양수입니다.**
- **급등처럼 사건 비율이 40% 안팎인 과제에서는 가중치 원래 확률도 꽤 정확합니다.** balanced는 확률을 50% 쪽으로 미는데, 실제 비율이 그 근처이기 때문입니다.
- **시도 급락 Linear는 모든 방식에서 음수입니다.** 2022년 금리 급등이라는 외삽 문제는 가중치와 무관합니다.

### 3. 경보 F1 (판정은 '항상 사건' 대비)

| 모형 | 시도 급등 (항상 0.45)<br>A 30% / A 50% / C 50% | 시도 급락 (항상 0.18)<br>A 30% / A 50% / C 50% | 서울 급등 (항상 0.63)<br>A 30% / A 50% / C 50% |
|---|---|---|---|
| Extra Trees | **0.67 ✅** / 0.50 △ / 0.63 ✅ | 0.51 ✅ / 0.50 ✅ / 0.46 ✅ | 0.66 △ / 0.50 △ / 0.51 △ |
| Random Forest | **0.69 ✅** / 0.43 △ / 0.64 ✅ | **0.57 ✅** / 0.52 ✅ / 0.23 △ | 0.71 △ / 0.59 △ / 0.51 △ |
| XGBoost | 0.49 △ / 0.37 △ / 0.66 ✅ | 0.52 ✅ / 0.47 ✅ / 0.38 ✅ | **0.72 △** / 0.63 △ / 0.71 △ |
| Linear | 0.48 △ / 0.49 △ / 0.53 △ | 0.43 ✅ / 0.44 ✅ / 0.46 ✅ | 0.70 △ / 0.68 △ / 0.51 △ |

**해석**
- **가중치 없음 + 30% 경보:** 시도 급등·급락에서 V17(C, 50% 경보)과 같거나 더 좋습니다.
- **가중치 없음 + 50%:** 확률이 실제 수준으로 낮아져서 급등에서는 경보가 적게 나옵니다. 30%가 더 맞습니다.

## 결론
1. **가중치를 빼도 전체 모형의 순위 실력은 유지됩니다.** 가중치는 주로 확률의 크기만 바꿉니다.
2. **가중치 없음(A)이 가장 단순하고 성능도 같거나 낫습니다.**
   - 확률 정확도는 트리 모형에서 C보다 대체로 높습니다.
   - 경보는 보정 단계 없이 '확률 30% 이상'으로 시도 급등·급락 모두 ✅입니다.
   - 보정용 과거 자료가 필요 없어서, 평가 시작이 늦어지지 않습니다.
3. **B(공식 되돌리기)는 트리 모형에는 쓰지 않습니다.**
4. **외삽 구간(2022 금리 급등)의 과대 확률은 어떤 방식으로도 해결되지 않습니다.** 한계로 기록합니다.

**최종안 제안:** 클래스 가중치를 빼고(A) 확률을 그대로 쓰고, 경보는 30%(주)와 50%(보조)로 둡니다. 보정 곡선은 진단용으로 함께 보고합니다.

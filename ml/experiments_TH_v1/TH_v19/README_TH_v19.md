# TH_v19: 짧은 기간 거시 변화(3·6개월) 추가와 금리 수준 제외 (2026-10-06)

로컬 전용입니다(`.git/info/exclude`).

## 배경
V18에서 2022년 하락기가 끝난 뒤에도(2023년 3~6월) 시도 급락 경보가 계속 켜졌습니다. 원인 진단은 다음과 같습니다.
- **기준금리 12개월 변화:** 2023.03에도 2.25, 2023.07에도 1.25였습니다. 1년 전과 비교해서 늦게 꺼집니다.
- **금리 수준:** 높게 유지됐습니다.
- **3개월 변화:** 2023.05에 0이 됐고, 이 시점이 실제 급락이 줄어든 시점과 맞습니다.

## 설계 (V18 기반: 클래스 가중치 없음, 전체 모형, Y1·Y3·Y4)

| 버전 | 변수 |
|---|---|
| V18 (기준) | 거시 변수 = 수준 + 12개월 변화, 또는 12개월 로그 변화 (경제변수 121개, 시도 기준) |
| **V19a** | 모든 해당 거시 변수에 **3·6개월 변화를 같은 규칙으로 추가** (241개) |
| **V19b** | V19a + **금리 변수 수준 제외** (이름에 '금리'가 들어간 6개, 235개) |

- 공급 흐름, 인구이동, 미분양, 더미는 그대로입니다.
- 그 밖의 설계는 V18과 같습니다.

## 해석
1. **2022~23년 후반 헛경보는 Linear·XGB에서 약 45% 줄었습니다.** 2023년 5월 경보가 15 → 6~7곳으로 줄었습니다. 금리를 12개월 변화와 수준으로만 보는 것이 경보 지속의 한 원인이라는 진단이 맞았습니다.
2. **가장 좋은 RF는 거의 변하지 않았습니다**(53 → 46). 2023년 3월까지는 모든 모형이 여전히 전부 경보를 냈습니다.
3. **2018~19년 하락기에서는 효과가 없었습니다.** 그 하락기는 금리 인상 때문이 아니었으므로, 이번 수정은 **금리 충격형 하락기에만 해당하는 처방**입니다.
4. **다른 과제의 손실이 있습니다.** Y1의 RF·ET가 일부 나빠졌고, 시도 급등 Linear가 크게 나빠졌습니다.
5. 이번 수정은 2023년을 보고 설계한 것이므로, 2022~23년에서 좋아진 것은 어느 정도 예상된 결과입니다. 다른 하락기(2018~19)에서는 효과가 없었습니다.

## 결론
- **주 모형은 V18을 유지합니다.**
- V19는 "경보 지속의 원인이 느린 금리 변수(12개월 변화, 수준)"라는 **진단 근거**로 보고합니다.
- 금리 충격기 경보 개선은 후속 과제로 둡니다. 예를 들어 금리 3개월 변화를 별도 '해제 신호'로 쓰는 방법이 있으며, 사전에 지정한 뒤 전향 검증해야 합니다.

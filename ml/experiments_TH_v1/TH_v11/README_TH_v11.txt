DFMBA TH v11 — 경제변수 + 가격모멘텀 전체형

1. 이번 설계
Y1: 향후 6개월 변화율
Y2: 양수 상승 / 음수 하락. 실제 정확히 0%인 자료만 Y2에서 제외.
Y3/Y4: 과거 학습 경로의 상위/하위 15% 급등·급락 기준 유지.
서울 25개 구 축소형과 별도 가속사건 정답은 제외.
입력 특징의 과거 3개월 가속 특징은 모멘텀 보조변수로 유지.
네 모형: Ridge/Logistic, Random Forest, Extra Trees, XGBoost.
공통 분기 재학습 및 알려진 과거 정답만 사용하는 확장창.

2. 문서
reports_TH_v11/국내월세지수_연구보고서_TH_v11.docx
reports_TH_v11/팀원공유_변경사항과실행안내_TH_v11.docx
두 문서는 별도입니다. 제목 11pt / 본문 10pt / 맑은 고딕입니다.

3. 실행
Python 3.12에서 검증했습니다. 가상환경을 만든 뒤:
python -m pip install -r requirements_TH_v11.txt
python ml/train_simple_TH_v11.py
python analysis/review_simple_TH_v11.py
python docs/build_reports_TH_v11.py
이전 버전 폴더와 API 키는 필요하지 않습니다. .env는 읽지 않습니다.
DFMBA_RUNTIME은 선택적인 로컬 Python 라이브러리 경로이며 인증키가 아닙니다.
라이브러리 설치가 완료된 환경에서는 이 변수 없이 실행할 수 있습니다.
V10 예측 대조는 인접 V10 폴더가 있을 때만 수행하는 선택적 추가 검증입니다.

4. 결과와 재현성
analysis/output_TH_v11: 현재 실행 결과.
팀원 공유패키지의 reference_results_TH_v11: 완료한 결과의 보존용 사본.
입력 파일과 코드 해시, 라이브러리 버전, 학습 구간, 선택 특징을 기록합니다.
Y2 주 지표는 기간 통합 Macro F1이며 연도별 클래스 부재도 별도로 확인합니다.
V10의 3범주·연도평균 F1과 직접 비교하여 개선이라고 주장하지 않습니다.
예측 점수는 AUC 진단용이며 확률 50% 운영 경보는 만들지 않았습니다.
같은 6개월 경로가 중첩되고 지역 충격도 공유되므로 행 수는 독립 표본 수가 아닙니다.
저장 모델은 이 작업에서 생성한 신뢰된 파일입니다. 외부의 불명확한 joblib은 열지 마십시오.

5. 범위와 보존
새 API 수집 / Supabase / 웹 / SHAP / 글로벌 / Y5는 이번 실행 범위가 아닙니다.
팀 DFMBA 저장소, 원자료 및 TH_v1~TH_v10을 변경하지 않았습니다.
GitHub push / PR / merge는 수행하지 않았습니다.
인증키와 .env는 공유패키지에서 명시적으로 제외합니다.
Word 목차의 갱신과 최종 렌더 검증은 Windows Word를 이용하였습니다.

6. 검증 중 경계 산식 정정
급락 경계의 수학적으로 같은 0.15와 1-0.85 표현이 부동소수점에서 달라
일부 경계 관측의 클래스가 바뀌는 것을 확인하였습니다.
V10과 동일한 1-0.85 산식으로 통일하고 최종 1024개 모델을 다시 학습했습니다.
초안은 V11 내부 QA 폴더에만 보존하며 최종 공유에 포함하지 않습니다.

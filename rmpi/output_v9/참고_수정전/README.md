2~12월은 1월 모형을 재사용하던 결함이 확인되어 매 결정월 재적합으로 고쳤다(커밋 07eba5d). 아래 파일은 고치기 전 실행의 결과를
'연 1회 적합' 민감도로 참고하기 위해 그대로 둔 것이다(결과 커밋 40045dd·feafbd6, 설정·입력은 본 실행과 같음).

- v9_s2_비교_연1회적합.csv: 6단계 ② 비교표 (M0·M1·M1′ 은 매달 갱신, M2·M3 는 1월 적합)
- v9_s3_민감도_연1회적합.csv: 6단계 ③ 민감도 (패널 M3 vs M2 행만 영향)
- v9_s7_TH비교_연1회적합.csv: 7단계 D TH V11 같은 행 비교 (corr_M2·M3 행만 영향)
- v9_s7_동인제거_연1회적합.csv: 7단계 A 동인 제거 (전부 영향)
